### <b>RAG Agent</b>

A <b>RAG (Retrieval-Augmented Generation) Agent</b>:

- Uses an LLM to generate commands (SQL, shell, etc.).
- Retrieves knowledge from a source (docs, DB).
- Your custom agent <b>executes</b> those commands (e.g., in terminal or database).

### <b>LLM Temperature</b>

- Controls creativity or randomness:
  - <code>0.0</code> → Deterministic, no creativity ("no hary").
  - <code>0.7–1.0</code> → Creative, varied output ("hary b2a")

An <b>AI agent crawling</b> usually means an automated program (the "agent") that <b>navigates through data sources</b>—like web pages, APIs, file systems, or internal services—<b>collecting and processing information</b> for some purpose.

In detail:

- <b>Agent</b> → An autonomous process that can make decisions, follow goals, and act without constant human input.
- <b>Crawling</b> → Systematically visiting and retrieving data from multiple locations (like a web crawler does for search engines).

### What is <b>Ollama</b>?

- <b>Ollama</b> is a tool that lets you <b>run AI models locally</b> on your machine (Mac/Linux, Windows in beta).
- Think of it as a <b>package manager + runtime</b> for AI models (like <code>npm</code> for JavaScript or <code>docker</code> for containers).

<code>brew services start ollama</code>

### What are we <b>pulling</b>?

When you run:

```bash
ollama pull nomic-embed-text
```

- You are <b>downloading a specific AI model</b> called <b>nomic-embed-text</b> from Ollama’s model library.
