# Study

Personal software engineering interview preparation: Java and Spring, frontend development, architecture patterns, project references, and principal-level self-assessment.

## Contents

- Java and Spring, frontend, and architecture cheat sheets
- Interview preparation notes and project discussion prompts
- A Java reference PDF and principal engineer self-assessment PDF

## Use

This is a reading and study collection, not a runnable software project. Open Markdown files in any Markdown editor and PDFs in a PDF reader. The notes cover Java/Spring, frontend development, architecture patterns, interview practice, and senior engineering topics.

Client-specific reference files, resumes, and unrelated practice exercises remain in the local source folder and are excluded from this public repository.
