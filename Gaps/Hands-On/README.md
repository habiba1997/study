# Hands-on gaps

These are exercises Habiba explicitly wants to perform by hand, one at a time, after a short explanation. Reading the instructions is not evidence of mastery. Use a disposable/local environment; discuss the observed result in chat and retest later.

- [PostgreSQL query-plan and index lab](PostgreSQL-Explain-Index-Lab.md): compare the same SELECT before and after a composite index.
- [JVM heap and GC diagnostics lab](JVM-Heap-Diagnostics-Lab.md): observe the memory trend and inspect retained objects using a running Java service, with no new code required.

- [Comparable, Comparator and streams sorting practice](Java-Sorting-Comparable-Comparator-Streams.md): important open gap; five progressive tasks to implement by hand, first without streams and then with streams. Includes email ordering, numeric ordering, tie-breakers, order filtering and mutation checks.
